# Учёт времени

Таймер рабочего времени для macOS. Приложение показывает итоги за сегодня, текущую неделю с понедельника и выбранный период. Обе даты периода включаются в расчёт. Время отображается в часах и полных минутах.

## Как пользоваться

- Нажмите **Начать отсчёт**. Повторное нажатие останавливает таймер.
- В блоке **Ручная корректировка** выберите дату, введите часы и минуты и нажмите **Добавить** или **Убрать**. Итоги обновятся сразу. Убрать можно время в пределах итога за выбранный день.
- Нажмите **Компактно**, чтобы оставить на экране плавающую кнопку. Слева она показывает число полных рабочих часов за сегодня. **Работать** запускает отсчёт, **Отдыхать** останавливает. Чтобы переместить кнопку, зажмите её левой кнопкой мыши и перетащите.
- Чтобы вернуться к отчёту, щёлкните компактную кнопку правой кнопкой мыши и выберите **Развернуть окно**. Также работает сочетание **⌘⇧M**.
- Закройте основное окно красной кнопкой или нажмите **⌘Q**. При выходе приложение сохраняет и останавливает текущую сессию. После принудительного закрытия сохраняется время до последней записи, которая обновляется каждую секунду.

SQLite хранит данные в `~/Library/Application Support/Time Tracking/time_tracking.sqlite3`.

## Запуск из исходников

Требуются macOS и Python 3.11 или новее.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m time_tracking
```

## Сборка приложения для Finder

```sh
.venv/bin/python -m pip install -r requirements-build.txt
.venv/bin/python -m PyInstaller --noconfirm TimeTracking.spec
open 'dist/Учёт времени.app'
```

Готовый пакет `dist/Учёт времени.app` можно открыть двойным щелчком в Finder.

## Проверка расчётов и сохранения
